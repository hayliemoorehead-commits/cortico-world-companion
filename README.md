# cortico-world-companion（主动陪伴）

Cortico World 扩展：按可配置的节奏把「陪伴时钟到点了」作为内部事件唤醒 bot——**说不说、说什么、做不做，完全由 bot 自主决定**；本 World 只负责让机会发生。

## 设计

- 间隔可配（默认 45 分钟，0 = 关闭）；深夜静默（默认 23:00–08:00）；
- 事件正文只陈述时钟事实，不带任何剧本；
- 遵循 Cortico 人格审美：以不作为为默认，需要约束用上下文语义而非机械阻拦。

## 配置（worlds.companion）

| 键 | 默认 | 说明 |
|---|---|---|
| `intervalMinutes` | `45` | 陪伴时钟间隔（分钟），0 = 关 |
| `quietFrom` / `quietTo` | `23` / `8` | 静默时段 |
